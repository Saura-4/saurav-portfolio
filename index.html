01. About

From chasing AI hype to owning the backend.

I started building AI tools to remove friction from my own workflow. Snip & Ask began when I got tired of screenshotting, switching tabs, and re-explaining context to an LLM. Scaling it past 1,700+ users and 75,000+ backend requests forced me to learn edge rate-limiting, model routing, and cost control for real.

During my FOSSEE Fellowship at IIT Bombay, I saw where naive LLM wrappers break: feeding raw circuit netlists to a local model caused hallucinations. The fix wasn't a better prompt — it was a deterministic Python extraction pipeline and a rule-based error engine before inference ever ran. That pulled me into RAG evaluation, then FastAPI & PostgreSQL backends, and then LangGraph agent loops.

Two lessons stuck: understand what a library is doing, not just its APIs, and writing code is the easy part — the real engineering is observability, traceability, cost control, and scaling after deployment.

FOSSEE Summer Fellowship · IIT Bombay · May – Jul 2026

eSim AI Assistant

At IIT Bombay, the existing assistant passed raw SPICE netlists directly to a local LLM, causing hallucinations when the model tried to infer circuit topology on its own. I redesigned the pipeline with a deterministic Python extraction layer that converts netlists and simulation state into verified facts before LLM inference — so the model explains facts instead of guessing them.

I also engineered a rule-based NgSpice error engine that detects, ranks, and suppresses cascading failures to isolate root causes, and built a hybrid offline mode that surfaces the extracted RAG context and structured diagnostics directly to users on machines without a local LLM.

deterministic extraction first → verifiable explanations second, even without an LLM.

Modular RAG Pipeline · BEIR Benchmarking · Built from Scratch

Modular RAG & Retrieval Benchmark

Seeing how backend context shapes LLM accuracy at IIT Bombay led me to build a swappable RAG pipeline from scratch: 6 chunking strategies, 4 retrieval strategies, and cited-span, abstention, and Chain-of-Verification generation across Gemini and Ollama.

Implemented Recall@k, Precision@k, MRR, and NDCG@k from scratch and benchmarked semantic, BM25-hybrid, and cross-encoder reranked retrieval on BEIR SciFact, ArguAna, and NFCorpus. Hybrid + reranking led on SciFact (0.665 NDCG@5) and NFCorpus (0.386), while plain semantic won on ArguAna (0.315). Profiling showed semantic + reranking came within 0.006 NDCG@5 of hybrid on SciFact at 0.3s vs up to 1.5s per query.

measure systematically → trade retrieval accuracy against real query latency.
