03. Projects

Modular RAG Evaluation Framework

A from-scratch RAG framework — no LangChain, no LlamaIndex — with interchangeable indexing, chunking, retrieval, reranking, generation, and evaluation modules. Benchmarked 4 chunking strategies against 4 retrieval pipelines on BEIR SciFact, implemented Recall@k, Precision@k, MRR and NDCG@k from scratch, and evaluated CoVe, Cited-Span and Abstain generation with a RAGTruth-inspired hallucination pipeline.

Production-ready chat platform backend with authenticated multi-user conversations, persistent history, and real-time SSE streaming. JWT auth, SQLAlchemy ORM, Alembic migrations, conversation ownership validation, layered CRUD, Redis caching — containerized with Docker and deployed.

Snip & Ask

Published Chrome extension with 540 organic users: snip any screen region and get contextual AI help without leaving the page. Guest Mode runs on a self-hosted Cloudflare Worker over Groq's free tier; Auto Mode performs OCR before inference, routes text through lightweight models, and falls back to vision models only when needed.
