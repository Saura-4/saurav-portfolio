Chrome extension · 2.5K+ installs · 1,300+ active users · 55K+ requests

Snip & Ask

This is where it started. I wanted to ask a question about something on my screen, and the honest options were: screenshot it, save it, switch tabs, and re-explain the context. So I built a Chrome extension that captures any region of the screen and answers questions about it — without leaving the page. Now live on the Chrome Web Store with 2.5K+ installs and 1,300+ users.

Making it work seamlessly at scale was the real education: a self-hosted Cloudflare Worker with D1-backed rate limiting for Guest Mode serving 55K+ API requests without requiring users to configure API keys. It features automatic model routing that passes captures through OCR to text models and falls back to vision models only when visual context is required, plus multi-provider support with BYOK and Compare Mode to evaluate multiple model responses.

the arc: idea → build → make it usable → 2,500+ users rely on it.

FOSSEE Summer Fellowship · IIT Bombay · May – Jul 2026

eSim AI Assistant

At FOSSEE, IIT Bombay, I worked on the eSim AI assistant — a project that changed how I think about LLM architecture. Rather than asking a local LLM to reason over raw circuit netlists directly, I redesigned the pipeline to extract circuit structure and simulation facts deterministically before LLM inference, ensuring the model explains verified facts rather than inferring them.

I engineered a rule-based NgSpice error analysis engine that detects, ranks, and suppresses cascading errors to surface root causes before generating explanations. Additionally, I developed an offline circuit analysis workflow that generates structured netlist summaries and error reports without requiring an LLM, and integrated it directly into eSim's Project Explorer to connect simulation failures directly to the assistant.

what clicked: deterministic extraction first → verifiable explanations second.

02

Modular RAG pipeline · BEIR benchmarking · built from scratch

Modular RAG & Retrieval Benchmark

Built a modular RAG pipeline completely from scratch with swappable ingestion, chunking (6 strategies), retrieval (4 strategies), and generation components (cited-span, abstention, Chain-of-Verification), supporting Gemini and local Ollama backends.

Wrote Recall@k, Precision@k, MRR, and NDCG@k from scratch and systematically benchmarked semantic, BM25-hybrid, and cross-encoder reranked retrieval on BEIR SciFact, ArguAna, and NFCorpus. Empirical findings showed hybrid + reranking scored highest on SciFact (0.665 NDCG@5) and NFCorpus (0.386), while plain semantic won on ArguAna (0.315). Analyzing the quality/latency trade-off revealed semantic + reranking came within 0.006 NDCG@5 of hybrid + reranking on SciFact at 0.3s vs up to 1.5s per query.

the point: measure systematically → optimize retrieval quality against real latency costs.

Backend · a learning project, on purpose

LLM ChatBot Backend

This one isn't an AI breakthrough, and I won't pretend it is. After working on AI systems, I realized I didn't understand the engineering underneath them well enough. So I built a chatbot backend specifically to learn it — properly, piece by piece.

FastAPI and PostgreSQL with SQLAlchemy, JWT authentication, Alembic migrations, a layered CRUD and service structure, conversation and message persistence, Redis caching, and streaming responses over SSE — containerized with Docker and deployed. The rule I set for myself: understand the mental model first, then write the code.

the engineering under an AI app, built by hand instead of assumed.
